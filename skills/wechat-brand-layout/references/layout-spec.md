# 浅蓝分区标准版

这是一套完整默认版式，不与任何机构身份绑定。换AI或换账号时保留本规范；素材建档只替换用户自己的Logo、封面、头尾图。主题数值以assets/themes.json为单一配置来源，本文解释用途。

## 页面与文字

| 项目 | 默认值 |
| --- | --- |
| 页底 | #f5fbff |
| 外层 | 左右10px，上下16px |
| 正文 | 14px；行高1.6；字距1px；#3e3e3e；默认字体 |
| 普通段落 | 两端对齐；首行2em；段后16px |
| 标题 | 二级16px；蓝底白字标签，两侧小方点；三级16px主题色 |
| 内容框 | 白底；1px #6ca1c3边框；内边距22px；组后26px |
| 导语框 | 同内容框；左上与右下20px圆角 |
| 结语框 | #edf7fd底；内边距26px；上方同级标题 |
| 图注 | 12px、#858585、居中 |
| 署名 | 12px、#858585、居中、透明底 |

分组采用group.variant=intro / section / summary。框内不要再嵌套完整模板或重复添加两层内边距。无导语、结语时不为了模板编造文字；栏目只影响语义分节。

## 照片与图组

单横图通常为框内90%，竖图72%，保持原比例。相关连续照片采用gallery：mode=row、width_percent=90、gap_px=8，每行2–3张。不是把图像烘焙成拼图；每张保留独立img与内嵌素材。更多照片可分成多行（4张用2+2），不同语义的图片通过分组或文段分开。

图片上下一样高不能靠裁主体实现；不同比例允许高度不同，顶部对齐。图注随实际左右/上下位置核对。涉及小字、长截图、二维码时，优先可读性，必要时按用户需求使用单图，不盲目套三列。

Word源图本身是拼图时需先视觉核验；清晰的照片边界可以拆分，保留来源和区域。名片、Logo、海报及信息图是完整设计，不当作照片拼接拆散。

## 常用组件

以下均由脚本生成可编辑结构，不依赖品牌图片：

- heading：标签分节标题及三级主题色小标题。
- group：导语圆角框、普通内容细框、浅蓝结语框。
- quote：主题色左竖线与浅蓝底的引语；不编造或改写原有引用。
- speaker：主题色加粗的已有发言人行；不补人名和履历。
- list_item：独立编号/项目符号，保持内容顺序。
- table：可编辑表格、浅蓝表头、可配置列宽，保持原文加粗。
- divider：32px短分隔线，用于确有结构需要的位置。
- end_mark：居中END，结语之后、署名之前。
- credit：透明背景署名，只使用本稿提供的人员。
- component：用户上传且确认用途的品牌素材。不内置或自动追加任何机构尾图。

## 跨工具一致性

先提取真实内容，再整理语义块，最后运行brand_layout.py render。不要让另一模型重新设计HTML/CSS或给每个栏目临时选择配色。脚本会把散列正文包入内容框、把无布局说明的连续照片组合为左右留缝图组、补齐结语组缺失的导航标题和END；原文、事实与图片内容仍守恒。

检查：页底是否浅蓝、标题是否蓝底白字标签、内容框22px留白、结语26px、同组照片是否独立且有8px间隙、署名是否透明底、是否误加品牌尾图。另看390–430px溢出、窄表和小字图可读性。不同AI仍可能在语义分组上有差别，不能只凭主题名就声称逐像素一致。
