# ll帮你喂给xiumi

独立Chrome／Edge扩展，配合本仓库的 `skills/wechat-brand-layout`。**不需要本地工作台、Node.js服务或AI API Key。** AI侧完成排版，插件只处理导入和核验。

1. 在扩展管理页开启开发者模式，加载本文件夹（直接包含manifest.json）。
2. 把Word与可选图片包交给AI，使用通用品牌排版skill，取得`article.xiumi.json`。
3. 登录秀米、新建空白图文，打开本插件并选择该文件。
4. 点击“导入正文与图片”，等待图片上传和正文写入。不要在导入过程中切换稿件。
5. 核对标题和摘要，在秀米手动保存。重新打开文章后，使用“保存并重开后，核验稿件”。

该数据包包含图片文件内容，无须逐张选择本地照片；账号权限和图片上传仍受秀米实际服务约束。插件不会自动发布。当前已通过模拟编辑器测试，真实账号导入与保存仍需验证。

数据仅存于浏览器扩展本地存储；无工作台连接、遥测或后台自动运行。上游导入核心及许可证见NOTICE.md与UPSTREAM-LICENSE。

## 0.5.1 图片上传兼容性修复

依据2026-10-18秀米公开14.6.7页面脚本，优先使用imageAPI.uploadImages的普通File上传通道，按图片顺序逐张处理；旧批量粘贴封装会吞掉异常，不再作为首选。缺少该服务时才兼容旧接口，不针对账号拒绝做绕过或自动换通道重试。

上传期间显示进度。失败说明包括图片序号、资源ID、大小、所用服务和可用的HTTP状态/服务错误；可下载错误说明，不含图片base64、Cookie或登录凭据。图片全部准备好后才写正文。

已通过普通File上传、兼容旧服务、权限错误和未知域名的模拟测试。用户真实失败的具体服务端原因仍需新版返回信息，不能据此声称真实账号已修复成功。

## 0.6.0 名称与图标

插件名称为“ll帮你喂给xiumi”，图标为小写ll。接收xiumi-bridge/v3格式的排版数据包。已加载过本目录的用户，在扩展管理页点击重新加载即可更新名称与图标。
